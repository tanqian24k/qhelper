## 3. 计算规格（§2.2 + §2.3，L44–71）

### 3.1 公式原文（§2.3 L57–64，整块引用）
```
BMR  = Mifflin-St Jeor：男 10×kg + 6.25×cm − 5×年龄 + 5
                             女 10×kg + 6.25×cm − 5×年龄 − 161
TDEE = BMR × 活动系数（久坐 1.2 / 轻度 1.375 / 中度 1.55 / 高 1.725）
缺口 = 每周速率(kg) × 1100        （换算依据：1 kg 体脂 ≈ 7700 kcal）
预算 = TDEE − 缺口                （随目标版本固定，不随运动/停滞自动调整）
下限 = 女 1200 / 男 1500 kcal（硬）｜BMR（黄警线）
```
